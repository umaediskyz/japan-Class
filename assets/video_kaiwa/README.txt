FOLDER VIDEO MP4 SIMULASI KAIWA (NIHONGO FOURNITY)
========================================================================

Folder ini disediakan untuk menaruh file video MP4 percakapan / tutor Kaiwa.
Sistem simulasi telpon Kaiwa akan secara otomatis mendeteksi dan memutar file
video MP4 sesuai dengan lawan bicara yang dihubungi:

DAFTAR NAMA FILE MP4:
1. aoi.mp4     -> Video untuk Aoi Sensei (Topik: Salam & Perkenalan Diri)
2. sakura.mp4  -> Video untuk Sakura-chan (Topik: Hobi & Kehidupan Shibuya)
3. yuna.mp4    -> Video untuk Yuna-san (Topik: Pesan Makanan di Kafe Kyoto)
4. hana.mp4    -> Video untuk Hana-senpai (Topik: Wisata & Belanja di Asakusa)
5. ren.mp4     -> Video untuk Ren-kun (Topik: Game & Percakapan Kasual)

SPESIFIKASI VIDEO YANG DISARANKAN:
- Format: .mp4 (H.264 / AAC)
- Rasio: Horizontal 16:9 (Landscape)
- Resolusi: 720p (1280x720) atau 1080p (1920x1080)
- Ukuran: Ringan (10MB - 50MB per video) untuk pemuatan kilat di browser.

FITUR FALLBACK OTOMATIS:
Jika file MP4 belum dimasukkan ke folder ini, web akan secara cerdas
mengaktifkan "Studio Simulasi Kaiwa Interaktif" dengan visualizer avatar,
gelombang suara live, serta subtitle dialog percakapan otomatis.
