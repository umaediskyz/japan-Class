📁 FOLDER ASSETS AUDIO VOICE NOTE (TRINITY NIHONGO)
====================================================================

Folder ini digunakan untuk menyimpan file MP3 Voice Note yang akan
diputar secara otomatis pada notifikasi Dynamic Island iOS.

Cara Menambahkan File Suara MP3:
1. Simpan file audio Anda dengan format .mp3 di dalam folder ini.
2. Anda bisa menamai filenya seperti contoh berikut:
   - vn1.mp3
   - vn2.mp3
   - vn3.mp3
   - aoi_sensei.mp3
   - voice.mp3

Sistem Dynamic Island akan otomatis mendeteksi dan memutar file audio
dari folder assets ini secara acak. Jika file MP3 belum dimasukkan,
sistem secara pintar menggunakan suara asli tutor Jepang (Web Speech)
sebagai cadangan otomatis sehingga tombol play dan animasi gelombang
suara RGB tetap aktif dan berfungsi 100%!
